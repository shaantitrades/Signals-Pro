# Publication Google Play Store - Signals Pro

## Checklist

1. [ ] Installer Bubblewrap (outil officiel Google pour TWA)
2. [ ] Générer le projet Android TWA avec Bubblewrap
3. [ ] Créer le fichier assetlinks.json pour la vérification Digital Asset Links
4. [ ] Générer les icônes Android à toutes les tailles requises
5. [ ] Mettre à jour le manifest.json PWA
6. [ ] Configurer le signing key (keystore)
7. [ ] Builder l'App Bundle (.aab)
8. [ ] Vérifier que tout est prêt pour le Google Play Console
